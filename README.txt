BUNNY BOT — Getting Started
============================

1) WHERE TO PUT THIS FOLDER
---------------------------
Put it somewhere you can write to: Documents or the Desktop.

    Do NOT put it in Program Files.
    Do NOT put it anywhere that needs administrator rights.

BUNNY BOT keeps its settings, accounts and statistics next to its own
executable, so it needs a folder it can write to. If you put it somewhere it
cannot write, it says so at startup and stops - rather than failing later with
half your data saved.

Prefer a folder that OneDrive or Google Drive is not constantly syncing: the
sync client copies the database while the bot is writing to it.


2) RUN IT
---------
Double-click:

    BUNNY_BOT.exe

If Windows warns about an unknown publisher, choose "More info" then "Run
anyway". The file simply is not signed with a publisher certificate yet.


3) ACTIVATE YOUR KEY
--------------------
The licence window opens on first run. Paste the key you were given:

    BB-XXXX-XXXX-XXXX

and press Activate. The key binds to this machine and is valid for one device.

    Lost your key? It is in your account on the website at any time.


4) SET UP THE EMULATOR
----------------------
    Resolution:  860 x 732
    DPI:         300

Then open Clash of Clans and leave it on the village screen.

    Tested and recommended:  LDPlayer

The program also connects to MEmu, NoxPlayer, BlueStacks, MuMu and GameLoop,
but those are not tested - check them with the readiness check first.


5) READINESS CHECK
------------------
Press "Readiness check" on the main page. It verifies the emulator connection,
the resolution, the DPI and that the game is present, and names whatever is
missing. Do not start until it is green.


6) PREPARE YOUR ARMY
--------------------
    Attack -> Prepare army

Pick the account, enter your camp, spell and siege capacity, then choose the
troops, spells and heroes. Each account has its own plan.

The bot will not start an attack if the plan is larger than the capacity, or if
a required card cannot be found in the game - it tells you instead of attacking
with an incomplete army.


7) START
--------
Press the green "Start bot" and follow everything from the statistics panel.


RUNNING MORE THAN ONE EMULATOR
------------------------------
Copy the whole bot folder for each emulator. One folder per window - never
share a single folder between two, as each copy keeps its own database and
settings.


UPDATES
-------
The bot checks for a new version at startup and offers it to you. Updates are
digitally signed and an unsigned update is refused. Your settings, accounts and
statistics survive the update.
